Objetivos de aprendizaje

Al finalizar esta guía, el estudiante podrá crear un proyecto de C#, reconocer su estructura básica, mostrar información, recibir datos del teclado y corregir errores sencillos de sintaxis.

CrearUn proyecto de consola en Visual Studio Community.
ComprenderEl archivo Program.cs, el método Main y las llaves.
EjecutarEl programa con Ctrl + F5.
MostrarMensajes con Console.WriteLine.
LeerInformación con Console.ReadLine.
CorregirErrores de mayúsculas, comillas, llaves y punto y coma.
Metodología de trabajoLee un paso, realízalo en Visual Studio y recién después continúa. No escribas diez líneas de una sola vez: programa, ejecuta, observa y corrige.

Observar el código inicial

No borres el código todavía. Primero identifica su estructura.

Program.cs · estructura tradicional
namespace MiPrimerPrograma
{
    internal class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello, World!");
        }
    }
}

¿Qué significa cada parte?

ElementoExplicación inicial
namespace MiPrimerProgramaEspacio lógico que organiza nuestro código. Puedes imaginarlo como una carpeta conceptual.
{ }Las llaves marcan dónde comienza y termina un bloque.
internal class ProgramDeclara una clase llamada Program. La clase organiza instrucciones, datos y comportamientos.
static void Main(...)Es el punto de inicio del programa. C# empieza a ejecutar las instrucciones que están dentro de sus llaves.
Console.WriteLine(...);Muestra información en la consola y luego baja a la siguiente línea.
Lectura por bloquesVisualiza la estructura de afuera hacia adentro: namespace → class → Main → instrucciones.

Console.Write("Carlos");		Escribe y permanece en la misma línea.HolaCarlos
Console.WriteLine("Hola");

Carlos
Uso prácticoUtiliza Write cuando deseas que el estudiante escriba su respuesta en la misma línea de la pregunta. Utiliza WriteLine cuando quieres pasar a una línea nueva.
11

Crear un programa interactivo

El programa dejará de mostrar información fija y empezará a recibir datos del usuario.

Program.cs · programa de bienvenida
namespace MiPrimerPrograma
{
    internal class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("================================");
            Console.WriteLine("   PROGRAMA DE BIENVENIDA");
            Console.WriteLine("================================");

            Console.Write("Escribe tu nombre: ");

            string? nombre = Console.ReadLine();

            Console.WriteLine();
            Console.WriteLine("Hola " + nombre);
            Console.WriteLine("Bienvenido a la materia de Programación II.");
            Console.WriteLine("Acabas de ejecutar tu primer programa interactivo.");

            Console.WriteLine();
            Console.WriteLine("Presiona una tecla para terminar.");
            Console.ReadKey();
        }
    }
}

Resultado esperado

================================ PROGRAMA DE BIENVENIDA ================================ Escribe tu nombre: Carlos Hola Carlos Bienvenido a la materia de Programación II. Acabas de ejecutar tu primer programa interactivo. Presiona una tecla para terminar.
Escribe el programa por etapasPrimero escribe el título y ejecútalo. Después agrega la pregunta. Luego crea la variable. Finalmente muestra el saludo. Así sabrás en qué paso apareció un error.

Entender la variable

Declaración y lectura
string? nombre = Console.ReadLine();
ParteSignificado
stringTipo de dato utilizado para guardar texto.
?Indica que el valor también podría estar vacío o ser nulo.
nombreNombre que damos a la variable.
=Operador de asignación: guarda el valor del lado derecho en la variable del lado izquierdo.
Console.ReadLine()Espera que el usuario escriba una línea y presione Enter.
;Finaliza la instrucción.
Imagina una cajanombre es una caja etiquetada. Cuando el usuario escribe “Carlos”, ese texto queda guardado dentro de la caja para utilizarlo después.
Uso de la variable
Console.WriteLine("Hola " + nombre);

El signo + une textos. En este contexto realiza una concatenación:

"Hola " + "Carlos" → Hola Carlos

Símbolos que utilizamos

( )
Paréntesis

Contienen los datos que enviamos a una función o los parámetros de un método.

{ }
Llaves

Abren y cierran bloques de código: namespace, clase, método, condición o ciclo.

" "
Comillas dobles

Indican que el contenido es texto.

;
Punto y coma

Marca el final de una instrucción.

.
Punto

Permite acceder a miembros como WriteLine dentro de Console.

=
Asignación

Guarda un valor en una variable. No significa “es igual” en todos los contextos.

14

Provocar y corregir errores

Los errores son parte normal del aprendizaje. Provoca cada error de manera controlada, observa el subrayado rojo y después corrígelo.

1. Falta el punto y coma

Console.WriteLine("Hola")Console.WriteLine("Hola");

C# puede mostrar un mensaje parecido a: Se esperaba ;

2. Mayúscula incorrecta

console.WriteLine("Hola");Console.WriteLine("Hola");

C# distingue entre mayúsculas y minúsculas.

3. Falta una comilla

Console.WriteLine("Hola);Console.WriteLine("Hola");

Las comillas deben abrir y cerrar el texto.

4. Falta una llave

static void Main(...) {
  Console.WriteLine("Hola");static void Main(...) {
  Console.WriteLine("Hola");
}

Una llave ausente puede producir varios mensajes de error.

Abre la Lista de erroresUtiliza Ver → Lista de errores. Empieza corrigiendo el primer error de la lista y vuelve a compilar; muchos errores posteriores pueden desaparecer.
No corrijas al azarLee el mensaje, observa la línea indicada y compara parejas: { }, ( ) y " ".

Cierre de la práctica

El objetivo de esta primera experiencia no es memorizar todo C#. El objetivo es comprender que un programa es una secuencia de instrucciones precisas, organizadas mediante símbolos y bloques. A partir de esta base construiremos variables numéricas, operaciones, decisiones, ciclos, métodos y objetos.
